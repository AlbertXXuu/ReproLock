# Packages

This directory is dormant. ReproLock currently remains one private root TypeScript application.

A physical package may be introduced only when a recorded current problem proves that a logical
module needs an independent consumer, release cycle, installation boundary, or compatibility
contract. The task must name the evidence, minimum acceptance condition, ownership, public entry
point, package-install smoke, and why a root module is insufficient.

The architecture's domain, evidence, runtime, browser, oracle, compiler, explorer, and CLI names
are logical boundaries. They are not instructions to create empty packages, provider adapters, a
plugin system, GitHub integration, Mutation tooling, or WebMCP support.
