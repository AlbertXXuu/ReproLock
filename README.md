# ReproLock

ReproLock is the provisional working name for an AlvenX pre-product candidate:

> Turn a messy browser bug report into a verified, durable Playwright regression test.

The repository is currently in Wave 0 foundation work. It contains no Issue parser, browser
explorer, oracle, compiler, GitHub Action, model provider, or released package. Product
implementation starts only if the architecture review and real historical Bug/Fix spike pass their
documented gates.

ReproLock is not yet a final product name. This local repository is not authorized for npm or
GitHub Release publication.
